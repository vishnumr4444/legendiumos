# User Flows

## Flow 1: Joseph launches an initiative
Login -> AI Command -> types "Launch Chapter 3 with Nano integration, Flipkart listing, and website release."
-> reviews 5 epics / 22+ tasks with owners, estimates, dependency chain, milestones
-> Approve & push to Jira -> items created, crew notified, Jira tickets opened
-> Dashboard shows new scope; risk feed and workload update live.

## Flow 2: Noel works a task
Login -> Your Missions shows assigned tasks sorted by due date
-> Board -> drags "Texture pass on environment kit" to In progress
-> comments "Blocked: waiting on final key art" -> AI flags [blocker], Amal notified
-> finishes -> drags to In review.

## Flow 3: Amal approves and rebalances
Login -> Team Command shows 1 pending approval -> opens item, reviews, drags to Done (Jira transitions)
-> Workload shows Noel at 95% -> applies AI suggestion moving a todo task to Vishnu (62%)
-> Vishnu gets an assignment notification.

## Flow 4: Anson tracks production risk
Vysakh comments "Vendor quote 18% above budget, urgent decision needed" on the PO task
-> AI flags [risk, urgent] -> Anson and Joseph notified -> item visible in executive risk feed
-> Joseph opens Reports -> executive brief (MD) for the leadership call.
